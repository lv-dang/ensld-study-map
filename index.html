🧭 How to read ENSLD questions

"standards-based / multivendor"OSPF, IS-IS, VRRP, BSR, OpenConfig. Never HSRP, GLBP, EIGRP or Auto-RP. "fastest convergence"Routed access, L3 triangles, BFD, summarization, stubs. "least config / simplest"Default routes to spokes, collapsed core, Fabric in a Box, DMVPN Phase 1. "scale"Summarize, stub areas, route reflectors, DMVPN Phase 3, larger fabric sites. "cost"Internet + overlay (DMVPN, SD-WAN) instead of more MPLS. "Choose two"The two answers usually belong together, like stub + summarization.

OSPF hub-and-spoke: where is the ABR? CSLG · ARCH
Few spokes → hub + spokes can share one area · many spokes → hub as ABR, spokes split into areas
Fewer spokes per area = less flooding at the hub, but less summarization
The hub needs to be the border router to summarize into and out of the spokes
OSPF vs IS-IS CSLG · ARCH · ENSLD
IS-IS L1 ≈ OSPF totally stubby internal router · L2 ≈ backbone · L1/L2 ≈ ABR
Never put L1-only routers between L2 routers (backbone must be contiguous)
Topologies: flat (small) · hierarchical (large) · hybrid
IS-IS has no NBMA or point-to-multipoint interface types · use MD5, not plaintext
EIGRP hub-and-spoke scaling ARCH · CSLG
Multiple EIGRP AS numbers do not stop queries. Summarization at the boundary does.
Dual hubs both summarizing → black hole via Null0 when a spoke link fails. Fix: hub-to-hub link / stub leaking.
Over 800 neighbors seen in production. Needs careful design.

⚠️ Classic traps

MED vs Local PrefMED influences inbound traffic from one neighbor AS. Local Pref controls outbound for your whole AS. Multiple EIGRP ASDoesn't stop queries, only delays them. DMVPN Phase 2Spoke-to-spoke yes, hub summarization no. GETVPNNot for public Internet/NAT paths. Totally stubbyCan't contain an ASBR. Use (totally) NSSA instead. 33 % LLQIt's a baseline. Size from real calls when numbers are given. IP transit (SD-Access)Doesn't carry SGT/VN natively (needs VRF-Lite + SXP or inline tagging). SD-Access and SD-WAN transits carry both. Dial-in vs dial-outDropped from the v1.1 blueprint. Focus on periodic vs on-change. HSRP active ≠ STP rootPut both on the same distribution switch, or traffic takes an extra hop over the inter-switch link. Weight vs local prefWeight is Cisco-only and stays on one router. Local pref is shared across the AS via iBGP. OSPF summarizationOnly on an ABR (inter-area) or ASBR (external). Never inside an area. Virtual linkCan't cross a stub area. The transit area must be a normal area. EIGRP stubStill receives routes. It just isn't queried and isn't used for transit. PoE+ 30 W30 W is at the switch port (PSE). Only 25.5 W reaches the device (PD). ISATAP vs 6to4ISATAP works inside one site. 6to4 connects sites across the IPv4 Internet. NAT64 aloneClients that connect by name also need DNS64 to get AAAA records. Fabric wirelessWLC must be ≤20 ms RTT from the APs. Otherwise use over-the-top wireless. Trust boundaryAt the access edge. PC markings aren't trusted; IP phones get conditional trust.
