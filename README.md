# ENSLD 300-420 Last-Minute Study Map

A single-page, mobile-first study tool for the Cisco **CCNP Enterprise Design (ENSLD 300-420) v1.1** exam. It's one self-contained `index.html` file: open it in any browser, online or offline.

**Live page:** https://lv-dang.github.io/ensld-study-map/

## What's inside

| Tab | What it does |
|---|---|
| 🗺️ Overview | Domain weights, an "Am I ready to pass?" panel, a 28-row blueprint coverage table, ~37 deep-dive panels with diagrams (step-by-step flows for LSAs, BGP, LISP, SD-WAN bring-up, NHRP, PIM-SM…) |
| 🃏 Trigger cards | ~200 requirement → solution flip cards with spaced repetition (10 min → 1 h → 1 day → 3 days) and diagrams on the back |
| 🎯 Scenario quiz | ~245 questions, mostly design scenarios: single choice, "choose two", ordering and drag-and-drop-style matching. Modes: Practice, Retry wrong, Weak topics, and a **timed mock exam** (60 questions weighted like the real exam, 90 minutes) |
| 🔢 Numbers | Ports, timers, defaults, scale limits, DSCP/AF grid, SD-Access/SD-WAN values, SNMP/syslog, HTTP codes |
| ⏱ Exam day | Pacing plan, one must-know line per blueprint sub-objective (1.1 – 5.6), classic traps |
| 🔍 Search | Search across cards, quiz, panels and numbers |

Every card and question is tagged with its official v1.1 sub-objective and a source label. Progress (cards, first-try quiz results, mock scores) is saved in your browser's localStorage. It stays on your device and doesn't sync between devices.

## Coverage

- Aligned with the official ENSLD v1.1 exam topics, including the v1.1 additions: Layer 2 security, gRPC/gNMI, cloud connectivity, and cloud service models.
- Topics dropped in v1.1 (dial-in/dial-out telemetry) are not included.
- Minimum per sub-objective: 5 cards, 5 quiz questions, 1 visual (Automation: 4 / 3 / 1).

## Sources

Original study notes and questions written from:
- CCNP Enterprise Design ENSLD 300-420 Official Cert Guide, 2nd ed. (ENSLD)
- Cisco ENSLD course guide (CSLG)
- CCDP ARCH 300-320 Official Cert Guide (ARCH) and ARCH Self-Study (ARCH-SS)
- CCDE 400-007 Official Cert Guide (CCDE)

Where the books disagree (e.g. SD-Access large-site size, UPOE+ cabling), the page shows both values. No exam dumps: all questions are original and written from the books' concepts.
